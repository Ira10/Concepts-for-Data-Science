# Basics

1. Python is formally an interpreted language (https://www.geeksforgeeks.org/python/understanding-the-execution-of-python-program/)
2. A program is a sequence of defintions and commands.
    -> Definitonas **evaluated** .
    -> Commands **executed** by Python Interpreter in a shell 
4. Everything is a object. Each object has a **type** tha5 defines the kinds of things programs can do to them.
5. Examaple: 30 (number), 'Ana' (string)
6. Scalar Objects (number - int, float, NoneType, boolean values), Non-Scalar (List, Dictionary, Sequence of characters "abc")
7. We can do _Type Conversion , but the object would be stored in a different location_



```
a = 5
print(a)
print(type(a))
print(id(a))
```
